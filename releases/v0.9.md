# NOLF Retro Widescreen Patch v0.9

First public release of a free widescreen patch for **No One Lives Forever**
(NOLF 1, version 1.003) that runs on **Windows 98 SE, Windows XP and newer**.
No modern runtime is needed.

**Creator:** Alexander Schmidt, alex-286@web.de

*This add-on is not made by or supported by Monolith Productions, or any of its
affiliates and subsidiaries.*

## Highlights

- Widescreen resolutions such as 1920x1080
- Centered, scaled menus, HUD, crosshairs and loading screens
- Widescreen cinematics, or 4:3 with black side bars
- Black side bars around the sniper scope
- New **Interface** options (HUD scale, cinematic aspect ratio)
- 60 fps framerate cap and optional FPS counter
- Developer console (**Shift+Esc**)
- Right-click closes popups; the last used ammo type is remembered per weapon
- Fixes: missing 3D weapon/item models, missing **Continue** button on the
  mission summary, crash on the Weapon Controls screen

See the [README](https://github.com/alex-286/nolf-retro-widescreen#readme) for the
full feature overview and the
[changelog](https://github.com/alex-286/nolf-retro-widescreen/blob/main/CHANGELOG.md).

## Installation

1. Download `NOLF-RETRO-WIDESCREEN.REZ` below and copy it to your NOLF folder,
   for example `C:\Games\NOLF\Custom\`.
2. In the NOLF Launcher click **Customize**, select the file, click **Add**,
   enable **Always load these rez files**, and click **OK**.
3. Start the game and pick a widescreen resolution under
   **Options → Display**.

Or start the game with `NOLF.exe -rez Custom\NOLF-RETRO-WIDESCREEN.REZ`.
To uninstall, remove the file from the Launcher's list or delete it. No
original game file is changed.

## Requirements

A licensed copy of NOLF 1, patched to version 1.003. The patch is free, works
only with a full copy of the game, and contains no game assets.

## Known limitations

- Client-side only; the developer console is disabled in multiplayer.
- Remembered ammo types reset when the game is restarted.

Please report problems via
[Issues](https://github.com/alex-286/nolf-retro-widescreen/issues) and attach
`RetroDebug.log` from the game folder.
